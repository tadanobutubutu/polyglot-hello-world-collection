# Polyglot Hello World Collection

A curated museum of **1470** real 'Hello World' programs. Every entry includes source code and a link to its dedicated file.

Entries are verified against trusted sources: [leachim6/hello-world](https://github.com/leachim6/hello-world), [Try It Online](https://tio.run), [GitHub Linguist](https://github.com/github-linguist/linguist), and common language references. Invented placeholder languages have been removed.

---

## Category Exploration

1. [Famous Languages](#famous-languages) — Industry standard languages with source code.
2. [Modern Languages](lists/modern.md) — Future-proof and high-performance.
3. [Legacy Languages](lists/legacy.md) — The foundations of the digital age.
4. [Esoteric Languages](lists/esoteric.md) — Artistic and mind-bending experiments.
5. [Research Languages](lists/research.md) — Theoretical and academic paradigms.

## Repository Structure
```
polyglot-hello-world-collection/
├── libraries/                    # Hello World sources organized alphabetically
│   ├── a/ through z/             # Alphabetical subdirectories (e.g., a/A-1/)
│   ├── symbols/                  # Symbol and number-based languages
│   └── nonenglish/               # Languages with non-English names
├── lists/                        # Categorized language lists (modern, legacy, A1, …)
├── source_of_truth_leachim6/     # Canonical snapshot from leachim6/hello-world
├── tio_languages.json            # Try It Online language catalog + Hello World tests
└── README.md                     # Main entry point
```

### About `source_of_truth_leachim6`

Vendored snapshot of [leachim6/hello-world](https://github.com/leachim6/hello-world). Primary authenticity and code reference for curating this collection.

### About `tio_languages.json`

Catalog from [Try It Online](https://tio.run) (`https://tio.run/languages.json`). Each entry includes display `name`, documentation `link`, and often `tests.helloWorld` with runnable source. **Purpose:** (1) prove a language exists on a public interpreter farm, (2) supply Hello World source when other references lack it. This file is an intentional dataset — keep it.
